# Faria Soroni — Portfolio

এই ফোল্ডারে আমার পোর্টফোলিও ওয়েবসাইট আছে। পুরো সাইট একটাই ফাইলে: `index.html`।

## ছবি যোগ করা
নিজের ছবিটার নাম `photo.jpg` দিয়ে `index.html` এর পাশে রাখুন। ছবি না থাকলেও সাইট ঠিকমতো চলবে।

## GitHub Pages দিয়ে লাইভ করা
1. github.com এ লগইন করুন।
2. ডানদিকে উপরে **+** → **New repository**।
3. Repository name দিন: `<your-github-username>.github.io`
   (যেমন: `fariasoroni21296.github.io`)। **Public** রাখুন। **Create repository** চাপুন।
4. নতুন repo পেজে **uploading an existing file** লিংকে ক্লিক করুন।
5. `index.html` আর `photo.jpg` টেনে এনে ছেড়ে দিন। নিচে **Commit changes** চাপুন।
6. **Settings** → বামদিকে **Pages** → Source: **Deploy from a branch** → Branch: **main**, ফোল্ডার **/ (root)** → **Save**।
7. ১–২ মিনিট পর সাইট লাইভ হবে: `https://<your-github-username>.github.io`

## পরে কিছু বদলাতে চাইলে
GitHub এ `index.html` খুলে পেন্সিল (✏️) আইকনে ক্লিক করে লেখা বদলান, তারপর **Commit changes** চাপুন। কয়েক মিনিটে সাইট আপডেট হয়ে যাবে।
